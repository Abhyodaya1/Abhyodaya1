## Selected Work

**[PulseWire](https://github.com/Abhyodaya1/Pulsewire)** · *Developer Observability for React Native*  
A developer tool for inspecting network requests, logs, navigation, device state, and runtime events directly from a running React Native app.

**[ORbit](https://github.com/Abhyodaya1/ORbit)** · *Realtime Video + Multiplayer Systems*  
A private 1:1 platform built around WebRTC, Socket.IO, synchronized multiplayer games, chat, and resilient reconnect pipelines.

**[Concord](https://github.com/Abhyodaya1/Concord)** · *C++20 + Distributed Systems*  
A from-scratch Raft consensus engine implementing leader election, log replication, persistence, fault injection, and replicated state.

**[FlightOps](https://github.com/Abhyodaya1/node_js_project)** · *Backend Architecture + Microservices*  
An airline ticketing backend exploring service boundaries, booking workflows, concurrency, APIs, and distributed data consistency.

**[FrameFlow](https://github.com/Abhyodaya1/FrameFlow)** · *React Native + Full-Stack Architecture*  
A video-sharing mobile application built around mobile-first product design, authentication, media storage, and social feeds.

**[ISL Translator](https://github.com/Abhyodaya1/ISLTranslator.app)** · *Computer Vision + ML*  
A real-time Indian Sign Language recognition system using hand-tracking, deep learning classification, and dynamic audio feedback.
